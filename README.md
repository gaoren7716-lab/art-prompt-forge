## 核心设计：七个面

每个风格体（画家、流派、名画）都被拆成同样的七个维度，这是「可解构」的前提：

- **媒介底材**（`medium`）—— 画面靠什么物质承载
- **笔法肌理**（`brush`）—— 痕迹是怎么留在画面上的
- **色彩关系**（`color`）—— 颜色之间怎么相处
- **光的处理**（`light`）—— 明暗怎么介入形体
- **空间构图**（`space`）—— 东西怎么摆、透视怎么走
- **固定母题**（`motif`）—— 这个人反复画的是什么
- **精神气质**（`spirit`）—— 画面背后那口气是什么

想要整条就七面全取；想要零件就只取一面；想要融合就甲的笔法 + 乙的色彩 + 丙的空间。
