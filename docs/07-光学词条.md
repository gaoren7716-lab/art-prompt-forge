# 横切光学词条

共 10 组、84 个词条。这一层是「谁都能用」的通用零件，勾选后按 slot 投进对应的面，永远追加在最后且不被截断。

与原子模块（`docs/10`）的区别：光学词条是**横向词表**，按类别组织、一次可多选；
原子模块是**带角色的单元**，一次只能指定一个角色，且约束类强制进负面。

每个词条都有独立编码（`OP-004` 这样），中文名也能直接用。
注意有 27 处词条与原子模块同名（内容一致、原子模块多带角色），
直接写中文名时默认命中原子模块，要指定本层的词条请用它的 `OP` 段编码。
