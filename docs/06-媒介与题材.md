# 媒介与题材

## 媒介 / 技法（28 条）

媒介的优先级是 80，高于画家（60）：挂上媒介，画家的物质层就要让位。

媒介还通过关系表与名画相连——`W-57` 用 `MD-02`，`W-56` 用 `MD-01`。

## 题材（26 条）

题材优先级 85，低于算子（100）但高于媒介（80）：它决定画面里有什么，且附带该题材默认的构图。
