# 冲突裁决规则

共 21 条，分四级。

## 为什么分级

把所有撞车都当成「二选一」是错的。灰调和高饱和确实互斥，但它们可以分区共存；
水墨和照片质感同框则属于实验性组合——允许，但必须标注未验证。
四种处理方式对应四种不同的用户处境：

| 级别 | 含义 | 引擎动作 | 谁该做什么 |
| --- | --- | --- | --- |
| `hard` 明确矛盾 | 两套语言在同一诉求下无法同时成立 | `ask` 静音低权重一方 | 使用者必须选一套 |
| `regional` 局部并存 | 整体冲突但可分配到不同区域 | `split` 给出分区建议 | 配合遮罩落实，或改用 region 模块 |
| `soft` 可共存 | 只是张力，不互斥 | `warn` 仅提示 | 什么都不用做 |
| `experimental` 实验性混合 | 允许但尚未验证 | `allow` 输出时标注未验证 | 知道自己在冒险即可 |

裁决逻辑：每条规则两侧各有一组语义标签，同一个人（或算子）同时具备两侧标签时触发。

```
得分 = 类型优先级 + 权重 × 10
算子优先级恒定为 100，代表用户明确意图，永不退让
```

类型优先级：`work` 40 < `movement` 50 < `painter` 60 < `medium` 80 < `subject` 85 < `operator` 100。
