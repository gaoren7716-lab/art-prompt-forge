# 手写大师签名卡

共 24 张。每张都是一份调好的 spec，直接喂给引擎即可出词。抄走之后还能改权重、换算子，所以它们不是终点而是起点。

每张卡下方都附了它派生的母版（`derived_from` 关系），改坏了能找回来。
