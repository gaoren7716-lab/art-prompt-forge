# 变形算子

共 38 个。算子是数据不是代码：往 `OPERATORS` 里加一项，引擎一行都不用改。

## 字段怎么读

| 字段 | 作用 |
| --- | --- |
| `keep` | 保留哪些面 |
| `only` | 只取这几面（解构专用） |
| `inject` | 往指定面塞词 |
| `add` | 追加散词 |
| `neg` | 追加负面词 |
| `tags` | 参与冲突裁决的语义标签 |

## 变形三字段

这是第二版加的：光说「变形」说不清变形会动什么、不能动什么，所以每个算子额外声明三件事。

| 字段 | 含义 | 引擎行为 |
| --- | --- | --- |
| `preserve` | 必须原样保留的面，变形的底线 | 其余来源在这些面上权重再高也不覆盖 |
| `change` | 变形实际要改的面 | 这些面上其他来源让位给算子 |
| `forbid` | 绝对不能出现的特征 | 直接进负面词，不参与权重调节 |

三字段由 `tools/gen_op_meta.js` 从 `keep` / `only` / `inject` **推导**得出，不要手写——
手写必然出现「既保留又改」的自相矛盾。改了算子结构就重跑生成器，它会校验交集与未归类面。
