# 名画

共 104 幅。名画自带 pri=40，低于画家 60，所以与画家同挂时画家语言压得住它；单独挂时得到的是这一次具体的构图与母题。

每条另附**收藏机构**与**承载材料**（取自关系表）：机构决定这张图的图像能不能商用，材料决定它占哪个媒介面。
