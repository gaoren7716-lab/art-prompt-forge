        黄金词序、四级冲突与状态徽章是怎么定的
        

          词序 = 权重：题材 → 空间 → 光 → 媒介 → 笔法 → 色彩 → 气质 → 署名 → 算子散词 → 画质。

          画质档自动判定：canvas 油画 / trad 矿物绢帛 / retro 做旧 / photo 摄影 / digital 数字。
          retro 档刻意不加 high resolution，否则会把龟裂与泛黄一起「修」掉。

          冲突分四级：明确矛盾自动让位 · 局部并存给分区建议 · 可共存仅提示 ·
          实验性混合允许但标注未验证。

          每条实体都带状态徽章：已收录只建了档 · 已编写能出词但没跑过模型 ·
          已测试跑过并留记录 · 已复核有外部来源交叉核对。
